# Ratnakar Baalkundhi — Portfolio

A responsive, single-page portfolio built with semantic HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

The site includes the supplied downloadable PDF resume at `resume/Ratnakar Baalkundhi.pdf`. Its favicon uses the portfolio logo at `images/logo.png`.

## Run locally

Open `index.html` in a browser; no server or build step is required. If you have Python installed and prefer a local server, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Deploy this folder as a static site using GitHub Pages, Netlify, Vercel, or another static hosting provider. Set the publish directory to the project root; there is no build command.

The portfolio and resume use the professional details supplied for this project. The AI explorations are independent works in progress, not completed products. Add profile links or demo URLs only when available and verified.
